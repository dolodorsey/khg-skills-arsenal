# KHG Grant Command

## Mission
Build a disciplined funding pipeline for eligible KHG entities without wasting time on low-fit grants or inventing eligibility.

## Source rule
Use current primary funder/government/foundation sources for eligibility, deadline, award size and requirements. Store source evidence and recheck material facts before submission.

## Opportunity score
Evaluate mission/initiative fit, entity eligibility, geography, use-of-funds match, award size, probability, competition, reporting burden, match requirement, document readiness and application effort.

## Go / No-Go
A grant only advances when eligibility is supported, use of funds fits a real objective, deadline is feasible, required documents can be produced, and expected value justifies effort.

## Execution loop
1. Search current funding sources.
2. Capture exact eligibility, deadline, award range and requirements.
3. Score fit, effort and win probability.
4. Create document-gap tasks immediately.
5. Build reusable narrative modules from verified entity facts and outcomes.
6. Draft application against funder rubric.
7. Require human review before final submission.
8. Save submission evidence and follow-up dates.
9. Track awarded/declined reasons to improve future scoring.

## Backend contract
Use `growth_grant_opportunities`, `growth_relationships`, `enterprise_objectives`, `tasks`, and `growth_automation_playbooks`.

## Quality bar
No stale grant lists. No fabricated statistics or outcomes. No final submission without human review. No missed deadline because a requirement was discovered late.
